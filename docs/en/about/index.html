About & maintenance disclosure

Who maintains this site?

Paperwork Fieldnotes is maintained through the GitHub account kolmo2026 by the same maintenance team developing tools for the Eqvero, KolmoPDF and KomoPDF ecosystem. These are related projects, not an independent review or third-party endorsement. No personal expert biography or institutional affiliation is claimed.

GitHub hosts the public source code; the live website is hosted on Vercel. The legacy GitHub Pages configuration is retained separately.

Processing and privacy

The open-source tools perform their documented calculations or file operations locally. This static site has no login, upload endpoint, analytics script or database. Loading the site still requests its public HTML, styles and JavaScript from the hosting provider. Following a product link leaves this site; the cloud service KolmoPDF uploads documents for processing, unlike these local utilities.

Scope and corrections

Examples are synthetic and are published with the source under MIT. Financial scenarios are explanations of stated inputs, not investment advice. Document checks cannot establish factual accuracy. Read each tool’s limitations before using a result.

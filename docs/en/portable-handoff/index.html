What to Keep When You Hand a Document Workflow to a Colleague

kolmo2026 maintenance team · Maintenance disclosure

Published 2026-11-03 · Updated 2026-11-04

Editorial update: maintenance attribution, publication dates and same-site related reading added; workflow examples unchanged.

The fastest way to discover an undocumented assumption is to move the work to a different folder—or a different person. A workflow that only runs in its author’s Downloads directory is not ready for a handoff. You do not need a large packaging system to improve it.

Sort the files by responsibility

Keep original PDFs unchanged. Treat calculator JSON and page-recipe JSON as editable instructions. Treat the generated PDF and terminal report as outputs that can be regenerated. The Markdown explanation belongs with its local figures, because moving only the text separates it from part of its meaning.

handoff/
  originals/
  instructions/
  notes/summary.md
  notes/figures/context.svg
  outputs/

Write a short plain-language instruction inside the note: which source becomes alias A, which period the income belongs to, and which command checks the note. A Page Recipe JSON contains filenames and counts, not the original PDFs. A Share Slice JSON contains inputs, not the company disclosure that supports them. Neither one replaces the originals directory.

Perform a move test

  1. Copy the whole handoff folder to a new location under your project.
  2. From outside it, run the Markdown CLI against handoff/notes/summary.md. Relative paths should resolve beside the note, not beside your terminal.
  3. Select the copied PDF originals in Page Recipe. Check the displayed aliases, then load the saved recipe and export to a fresh output filename.
  4. Reload the share scenario and compare the final row with the note’s stated result and units.

The pass condition is not “all tools opened.” It is that the same inputs produce the same numerical scenario, the same source-page sequence and usable local note links after relocation. A missing figure is a handoff failure even if the text renders.

Keep the environment note small

Record Node 24 or newer for the CLI and builds; use npm ci in each repository to follow its lockfile. The two browser utilities require JavaScript and enough memory for their inputs. Do not copy credentials, browser profiles, private customer documents or node_modules into a public handoff.

When a paper still needs conversion, the related KolmoPDF cloud service is a different processing boundary: documents are uploaded there. This handoff exercise starts from local files and does not quietly move that boundary.
